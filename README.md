# 🏭 Maxvent Tools — Производственная система цеха вентиляции

Современное веб-приложение (PWA) для управления цехом вентиляции: расчет спецификаций воздуховодов и фасонных изделий, 1D оптимизация раскроя шинорейки, 2D раскрой листового металла, учет сдельной выработки мастеров и финансовый контроль.

---

## 🚀 Основные возможности

1. **Спецификация и изделия**:
   - Прямоугольные и круглые воздуховоды, переходы, отводы, заглушки, врезки, тройники, крестовины, вытяжные зонты.
   - Автоматическое суммирование одинаковых позиций при вводе.
   - Конструктор изделий с возможностью добавлять свои типы и параметры.
   - Массовое редактирование позиций (металл, толщина, тариф, мастера).
   - Быстрое переключение статусов: **`Не готово`** ⏳ и **`Готово`** ✓.

2. **Шинка (Раскрой шинорейки 1D)**:
   - Автоматический расчет требуемых рамок под прямоугольные воздуховоды и фасонину.
   - Оптимизированная раскладка по стандартным пачкам (10 хлыстов по 3 метра) с минимизацией отходов.
   - Учет обрезков для каждого объекта и отдельный автономный калькулятор.

3. **Раскрой листа 2D**:
   - Автоматическая раскладка разверток прямоугольных воздуховодов на стандартные листы металла (2500 × 1250 мм).
   - Интерактивная отрисовка карт раскроя на Canvas с экспортом в PDF.

4. **Учет выработки и сдельная оплата мастеров**:
   - Авторизация по персональному PIN-коду.
   - **Умное разделение заработка**: по умолчанию Чингис получает 50%, а остальные мастера делят 50% поровну (или 100% поровну без Чингиса).
   - Личный кабинет мастера: начисления, готовность по объектам, печать ведомости выработки.

5. **PWA (Progressive Web App)**:
   - Установка как нативное приложение на Android, iOS и Desktop.
   - Оффлайн-кэширование через Service Worker.

---

## 🛠 Технологический стек

- **Frontend**: HTML5, Vanilla JavaScript (ES6+ Modules), Tailwind CSS.
- **Backend / База**: Supabase (PostgreSQL, Auth, Realtime REST).
- **Деплой**: GitHub Pages (автоматический деплой из ветки `main`).

---

## 📁 Структура проекта

Код системы полностью разделен на независимые модули:

- `js/config.js` — Настройки Supabase, константы, глобальное состояние (`appState`, `session`).
- `js/auth.js` — Авторизация мастеров и переключение режимов.
- `js/projects.js` — Управление объектами и фальцевыми припусками.
- `js/items.js` — Форма изделий, динамический ввод, спецификация и групповые действия.
- `js/flange.js` — 1D раскрой шинорейки и управление обрезками.
- `js/nesting.js` — 2D раскрой листа на Canvas и PDF.
- `js/finance.js` — Учет финансов и платежей.
- `js/dev.js` — Конструктор изделий, кастомные параметры, архив.
- `js/workers.js` — Расчет долей, личный кабинет выработки и KPI.
- `js/main.js` — Точка входа и инициализация.
